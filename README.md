# 坑記（暫名）

考古探坑紀錄工具：把多個坑位的**位置、距離、高低關係**和**坑內的層位、遺物、遺構**放在一起，2D／3D 切換檢視。由「房間擺設 Room Planner」延伸而來。

> 內建的「海角示範遺址」是**虛構資料**（名稱、座標、高程、人員、遺物皆非真實），只用來展示功能。

## 功能（v0.1）
- **兩層座標**：遺址層用 TWD97 TM2（EPSG:3826，公尺），坑內用局部座標（距西壁、距南壁，cm）。基準點可輸入 TWD97 或經緯度，自動互換。
- **專案＝遺址、底下分季次**：同一遺址不同年度的發掘放在同一張圖上，可依季次上色／隱藏。坑號＝`代號-季次/坑號`（例：`JL-114/P4`）。
- **探坑**：依網格（2 m）自動定位，或輸入 RTK 實測四角；自動檢查邊長、對角線差、偏轉。
- **高程**：內部以「相對基準點」記錄。輸入可用海拔、相對 BM、水準儀讀數（後視／前視）或距坑口深度；顯示可一鍵切換海拔／相對 BM／距坑口。
- **層位**：人工層／自然層兩種都記錄，專案設定選一種為主。
  - 人工層：依深度切，遺物自動依深度歸層。
  - 自然層：全遺址共用的層位定義（用來對應不同坑的同一層），各坑填層界四角高程，可尖滅；遺物以記錄者指定為準，與深度不符時提醒。
- **層位紀錄表單**：日期、記錄者、四角高程、Munsell 土色（顯示近似色）、土質、緊實度、包含物、照片編號、字卡預覽（`JL-114 / P4 / L0 / 20250722`）。
- **遺物**：點的方式標示，依類別上色（陶、瓷、石、骨角、金屬、貝、動物骨骼、樣本…），特物以菱形表示；可附手繪圖／照片。
- **遺構**：柱洞、灰坑等（圓形／方形＋頂底高程）。
- **視圖**：
  - 遺址平面：網格、季次、量兩坑的中心距離、最近邊距、方位角、坑口／坑底高差
  - 坑位平面：逐層檢視（底色＝該層土色）、四角高程、拖曳調整遺物位置
  - 剖面：四面坑壁，主要層位填色、另一種層位以虛線疊加，遺物依離壁距離變淡
  - 3D：挖掉的土柱依層上色、遺物浮在實際深度；垂直誇張、透明度、逐層剝除、透視遺物
- **匯出**：GeoJSON（TWD97 或 WGS84，可直接拖進 QGIS）、遺物清冊 CSV、層位紀錄 CSV、archeoViz CSV；備份檔（含圖片）匯出／匯入。

## 技術
純靜態網頁（ES modules，無建置步驟），Three.js 由 CDN 載入，資料存在瀏覽器 IndexedDB。發佈前跑 `python3 bump.py <版本>` 更新所有模組網址的版本號。
